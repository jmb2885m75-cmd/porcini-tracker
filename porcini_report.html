How observations are submitted and saved

Submit queues a GitHub Actions workflow that validates the observation and commits it to harvest_log.json; it appears here after the workflow finishes and the report is regenerated. Your token is stored in this browser's localStorage. If GitHub rejects the request, nothing is lost: fix the form or use Save as draft, which stays only in this browser. A no-find report caps that day's score at 20.
